# Portfolio Frontend

Modern React portfolio frontend with animations and dark mode.

## Features

- ⚡ React 18 with Vite
- 🎨 Tailwind CSS for styling
- 🌙 Dark mode support
- ✨ Framer Motion animations
- 📱 Fully responsive
- 🔐 Admin panel with authentication

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Build

```bash
npm run build
```

## Environment Variables

Make sure your backend API is running on `http://localhost:8000` or update the proxy in `vite.config.js`.
